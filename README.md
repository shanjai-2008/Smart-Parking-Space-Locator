# Smart Parking Space Locator

A Python desktop application that helps users discover nearby registered parking facilities and rank them based on geographic distance and availability.

## Overview
The application uses location-based search, geographic distance calculations, and data structures to help identify nearby parking facilities.

## Technologies Used
- Python
- Tkinter
- Min-Heap
- JSON
- Geopy
- OpenStreetMap

## Key Features
- Parking facility registration
- Location-based parking search
- Distance calculation using the Haversine formula
- Min-heap based ranking of nearby parking facilities
- Parking availability management
- Booking functionality
- Parking fee and change calculation
- Map visualization

## How It Works
1. Retrieve or enter a user's location.
2. Calculate the distance to registered parking locations.
3. Rank available parking facilities using a min-heap.
4. Display relevant parking options.
5. Allow users to manage bookings and parking information.

## Purpose
Demonstrates the application of data structures, geographic calculations, and Python GUI development to a real-world parking problem.
